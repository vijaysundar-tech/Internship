# Lesson 3 – Import Excel Datasets

## Project Overview
This project focuses on importing, exploring and analysing a public student performance dataset using Python.

## Dataset Source
- **Source:** UCI Machine Learning Repository
- **Dataset:** Student Performance
- **URL:** https://archive.ics.uci.edu/dataset/320/student+performance
- **Records analysed:** 395 students
- **Columns:** 33

The original Mathematics dataset was provided as a CSV file. I converted it into an Excel workbook and imported it using Pandas `read_excel()`.

## Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Tasks Performed
1. Downloaded and extracted the public dataset.
2. Imported the dataset using Pandas.
3. Converted CSV data into Excel format.
4. Imported the Excel workbook using `read_excel()`.
5. Explored the dataset using `head()`, `info()` and `describe()`.
6. Calculated average, highest, lowest and median marks using NumPy.
7. Created a bar chart to compare examination marks.
8. Created a histogram to understand the distribution of final marks.

## Key Findings
- The dataset contains 395 student records and 33 columns.
- No missing values were found.
- Average first-period marks: 10.91.
- Average second-period marks: 10.71.
- Average final Mathematics marks: 10.42.
- Highest final mark: 20.
- Lowest final mark: 0.

## Conclusion
Through this project, I learned how to import Excel datasets using Pandas, perform numerical calculations using NumPy, explore data and create charts using Matplotlib.

This project improved my understanding of basic data analysis with Python.
