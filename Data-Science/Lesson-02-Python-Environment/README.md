# Lesson 2: Install Python and Configure Environment

## Project Overview
This project demonstrates basic data analysis using Python and the Iris Flower Dataset.

## Dataset Source
UCI Machine Learning Repository – Iris Dataset

https://archive.ics.uci.edu/dataset/53/iris

## Tools and Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Completed
1. Configured the Python environment.
2. Installed the required Python libraries.
3. Loaded the Iris dataset.
4. Explored dataset information.
5. Calculated statistical summaries.
6. Checked missing values.
7. Created visualizations.
8. Analysed the results and wrote conclusions.

## Key Findings
- The dataset contains 150 records.
- There are three Iris flower species.
- Each species has 50 records.
- No missing values were found.
- Petal lengths differ between flower species.
- Iris-setosa generally has smaller petals.

## What I Learned
I learned how to use Python for data analysis, work with datasets using Pandas and NumPy, create charts using Matplotlib and Seaborn, and interpret data findings.
