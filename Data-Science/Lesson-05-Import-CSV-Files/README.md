# Netflix Movies and TV Shows – Data Analysis

## About the Project
This project explores the Netflix Movies and TV Shows dataset using Python. The goal is to understand Netflix content through data analysis and visualization.

## Dataset
- **Source:** Kaggle
- **Dataset:** Netflix Movies and TV Shows
- **File:** netflix_titles.csv
- **Link:** https://www.kaggle.com/datasets/shivamb/netflix-shows

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed
1. Imported CSV data using Pandas.
2. Explored the dataset using head(), info(), shape and describe().
3. Counted Movies and TV Shows.
4. Analysed Netflix content by country.
5. Examined content by release year.
6. Identified missing values.
7. Handled missing values using fillna().
8. Analysed the most common genres.
9. Created visualizations using Matplotlib.

## Key Findings
- Movies are more common than TV Shows in the dataset.
- The United States is a major contributor to Netflix content.
- Netflix contains titles from different release years.
- Some columns contain missing values.
- Genre distribution shows that some genres are more common than others.

## Conclusion
This project helped me learn how to import CSV files, explore data, clean missing values, perform basic data analysis and create charts using Python libraries.
