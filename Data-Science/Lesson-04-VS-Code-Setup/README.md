# Lesson 4 – Set up VS Code or PyCharm

## Project Overview
This project demonstrates data analysis and visualization using Python in Visual Studio Code with a Jupyter Notebook.

## Dataset
- **Name:** Red Wine Quality Dataset
- **Source:** UCI Machine Learning Repository
- **Records:** 1,599
- **Columns:** 12

Dataset link: https://archive.ics.uci.edu/dataset/186/wine+quality

## Tools and Technologies
- Python 3.13.5
- Visual Studio Code
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Work Performed
1. Set up Python and Jupyter in VS Code.
2. Imported the required Python libraries.
3. Loaded the Red Wine Quality dataset.
4. Explored the dataset using Pandas.
5. Analysed wine quality distribution.
6. Created visualizations using Matplotlib and Seaborn.

## Visualizations
1. Distribution of Wine Quality Scores.
2. Average Alcohol Content by Wine Quality.

## Key Findings
- The dataset contains 1,599 wine samples.
- Most samples have quality scores of 5 and 6.
- Quality score 5 has the highest number of samples.
- Higher quality scores generally show higher average alcohol content.

## What I Learned
I learned how to configure a Python environment in VS Code, use Jupyter Notebooks, import public datasets, perform basic data analysis, and create charts using Python libraries.

## Conclusion
This project helped me understand the basic workflow of a Data Science project, from loading a public dataset to analysing and visualizing the results.
