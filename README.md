# Internship - Power BI and Excel

## Project: Iris Flower Dataset Analysis

### Objective
To analyse the Iris flower dataset using Python and understand data analysis and visualisation.

### Dataset Source
UCI Machine Learning Repository:  
https://archive.ics.uci.edu/dataset/53/iris

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

### Work Completed
1. Imported the Iris dataset.
2. Checked dataset information and shape.
3. Checked missing values.
4. Counted flower species.
5. Calculated statistical summaries.
6. Created two visualisations.
7. Added findings and conclusions.

### Key Findings
- Total records: 150.
- Total species: 3.
- Each species has 50 records.
- No missing values.
- Average petal length: 3.76 cm.

### Conclusion
This project helped me understand basic data analysis and visualisation using Python.
